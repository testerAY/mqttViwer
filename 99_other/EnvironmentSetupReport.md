# 環境構築レポート

**日付:** 2025-12-30

## 目的
Tauri, Rust, Vue.js を使用したMQTT Web Viewerアプリケーションのローカル開発環境を構築する。

## 実行サマリー
設計資料に基づき、必要なツールチェーンのインストールからプロジェクトのセットアップ、起動確認までの一連の作業を実施しました。途中、いくつかのエラーが発生しましたが、都度解決策を適用し、最終的に環境構築を完了させました。

## 詳細な手順

### 1. 事前調査
- `00_Document/` 内の `RequirementsSpecification.md`, `DetailedDesign.md`, `UIDetailedDesign.md` を読み込み、プロジェクトの要件と技術スタック（Tauri, Rust, Vue.js）を確認しました。

### 2. ツールチェーンのインストールと設定
- **Rust:**
    - `rustup`がインストールされていないことを確認し、`winget`コマンドでインストールしました。
    - `stable-x86_64-pc-windows-msvc` ツールチェーンをインストールし、デフォルトに設定しました。
- **Node.js:**
    - `node -v` および `npm -v` コマンドで、開発に十分なバージョンがインストール済みであることを確認しました。
- **Tauri CLI:**
    - `cargo install tauri-cli` コマンドを実行し、Tauriの開発用コマンドラインツールをインストールしました。

### 3. プロジェクトのセットアップ
- `cargo tauri init` では対話式プロンプトにより自動化が困難だったため、方針を変更しました。
- ユーザーに `npm create tauri-app@latest` コマンドを手動で実行してもらい、Vue 3 + TypeScript のプロジェクトテンプレートを生成しました。
- `npm install` を実行し、フロントエンドの依存関係（ライブラリ）をインストールしました。

### 4. 発生したエラーと対応
環境構築の過程で、以下の2つの主要なエラーが発生しました。

#### エラー1: C++リンカーが見つからない
- **発生タイミング:** `cargo install tauri-cli` の実行中
- **エラーメッセージ:** `linker 'link.exe' not found`
- **原因:** RustコードをWindowsアプリケーションとしてビルド（リンク）するために必要な Microsoft C++ Build Tools (MSVC) がシステムにインストールされていませんでした。
- **解決策:** ユーザーに**Visual Studio Installer**を起動し、「**C++によるデスクトップ開発**」ワークロードをインストールしていただきました。

#### エラー2: cargo コマンドが見つからない
- **発生タイミング:** `npm run tauri dev` の実行中
- **エラーメッセージ:** `cargo metadata... program not found`
- **原因:** `rustup` によってインストールされた `cargo.exe` の格納ディレクトリ (`C:\\Users\\yuta_\\.cargo\\bin`) が、システムの環境変数 `PATH` に登録されていませんでした。
- **解決策:** ユーザーにシステムのプロパティから環境変数 `PATH` を編集していただき、上記のパスを追加することで解決しました。

### 5. 最終確認
- 再度 `npm run tauri dev` を実行し、Rustバックエンドのコンパイルとフロントエンドの開発サーバーが正常に起動することを確認しました。
- これにより、アプリケーションの開発準備が整いました。

## 結論
以上の手順を経て、本プロジェクトの開発環境は無事に構築完了しました。
